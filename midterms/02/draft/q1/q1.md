## Deep Learning Architectures: Dense, Convolutional, Recurrent, and Transformer Models

All four architectures learn a parameterized function

$$
\hat{y}=F_{\theta}(x),
$$

where \(x\) is the input, \(\hat{y}\) is the prediction, and \(\theta\) represents the trainable parameters. Their main difference is the structural assumption they use to process data: dense networks assume flat feature vectors, convolutional networks assume local spatial structure, recurrent networks assume temporal order, and Transformers assume global pairwise relationships.

## 1. Dense Neural Networks

A dense or fully connected layer maps every input from the previous layer to every output unit:

$$
h^{(\ell)}=\phi\!\left(W^{(\ell)}h^{(\ell-1)}+b^{(\ell)}\right),
$$

with

$$
W^{(\ell)}\in\mathbb{R}^{m_\ell\times m_{\ell-1}},\qquad
b^{(\ell)}\in\mathbb{R}^{m_\ell}.
$$

The principal layers are an input feature vector, one or more dense layers, nonlinear activations, and an output layer. Dense networks are flexible and useful for tabular prediction, regression, risk scoring, and baseline models. Their limitation is that they do not naturally exploit spatial, sequential, or relational structure.

## 2. Convolutional Neural Networks

For image-like or grid-like data, a convolutional layer computes local filtered responses:

$$
Y_{i,j,k}=\phi\!\left(
b_k+\sum_{u,v,c}K_{u,v,c,k}X_{i+u,j+v,c}
\right).
$$

Here, \(K\) is a learnable filter shared across spatial locations. The principal layers are the image or grid input, convolutional filters, feature maps, activation functions, pooling or downsampling layers, and a dense or classifier head.

CNNs exploit locality, parameter sharing, and translation equivariance. They are representative architectures for image classification, object detection, segmentation, medical imaging, satellite imaging, visual inspection, and spectrogram analysis. Their main limitation is that long-range context usually requires additional depth, dilation, pooling, or attention.

## 3. Recurrent Neural Networks

A basic recurrent network processes a sequence one element at a time:

$$
h_t=\phi(W_xx_t+W_hh_{t-1}+b_h),
\qquad
\hat{y}_t=g(W_yh_t+b_y).
$$

The hidden state \(h_t\) acts as a memory of the previous elements. The principal layers are the ordered inputs, a shared recurrent cell applied through time, hidden states, and an output layer. LSTM and GRU models add gates to control memory and reduce vanishing-gradient effects.

RNNs are designed for time series, speech processing, language modeling, biomedical signals, control systems, and other ordered data. Their main limitation is that recurrence is sequential, which makes training harder to parallelize and can create unstable gradients in long sequences.

## 4. Attention-Based Architectures and Transformers

Transformers use self-attention. Given an input representation \(X\), they compute

$$
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V,
$$

and

$$
\operatorname{Attention}(Q,K,V)
=
\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.
$$

The attention matrix determines how much each token, patch, or element should attend to every other element. The principal layers are token or patch embeddings, positional encoding, multi-head self-attention, normalization, feed-forward layers, and an output head.

Transformers are powerful for large language models, translation, text classification, Vision Transformers, multimodal learning, protein modeling, code generation, and medical AI. Their main limitation is that standard self-attention has \(O(n^2)\) cost with respect to the input length.

## Comparison Summary

| Architecture | Best suited for | Main operation | Main inductive bias | Main limitation |
| --- | --- | --- | --- | --- |
| Dense | Flat numerical or categorical feature vectors | Matrix multiplication plus nonlinearity | Direct interaction among all features | Ignores spatial or temporal structure unless it is engineered into the input |
| CNN | Images, grids, spatial signals, spectrograms | Convolution and pooling | Locality, parameter sharing, translation equivariance | Limited native long-range context |
| RNN | Ordered sequences and temporal signals | Recurrence through a hidden state | Temporal order and memory | Sequential training and gradient instability in long sequences |
| Transformer | Text, long sequences, image patches, multimodal data | Scaled dot-product self-attention | Global pairwise interaction | Quadratic attention cost for long inputs |

## Similarities and Differences

All four architectures are trained by optimizing a loss function, commonly with gradient-based methods such as stochastic gradient descent or Adam. They use nonlinear transformations, can be stacked into deep models, and can solve classification, regression, and representation-learning tasks.

The key difference is the way each architecture incorporates assumptions about the data. Dense networks provide a general all-to-all mapping for feature vectors. CNNs specialize in local spatial patterns. RNNs specialize in ordered temporal dependencies. Transformers specialize in global interactions among all input elements. Therefore, the best architecture is the one whose inductive bias matches the structure of the problem.
