# Infographic Draft

## Deep Learning Architectures: Dense, Convolutional, Recurrent, and Transformer Models

### Central idea

All four architectures are neural networks that learn a function

[
\hat{y}=F_{\theta}(x)
]

where (x) is the input, (\hat{y}) is the prediction, and (\theta) represents trainable parameters.
They differ mainly in **how they process structure** in the data: independent features, spatial locality, temporal order, or global relationships.

---

## 1. Dense Neural Networks

### Mathematical model

A dense layer connects every input neuron to every output neuron:

[
h^{(l)}=\phi\left(W^{(l)}h^{(l-1)}+b^{(l)}\right)
]

where:

[
W^{(l)} \in \mathbb{R}^{m_l \times m_{l-1}}, \qquad b^{(l)} \in \mathbb{R}^{m_l}
]

and (\phi) is an activation function such as ReLU, sigmoid, or tanh.

### Layer diagram

```text
Input features
[x1, x2, ..., xn]
      ↓
Dense layer
      ↓
Activation
      ↓
Dense layer
      ↓
Activation
      ↓
Output
```

### Core idea

Dense networks treat the input as a **flat vector**. Every neuron receives information from every input of the previous layer.

### Strengths

They are simple, flexible, and useful for tabular data or low-dimensional numerical problems.

### Weaknesses

They do not naturally exploit spatial, sequential, or relational structure. For images or sequences, they often require too many parameters.

### Applications

Classification, regression, tabular prediction, function approximation, risk scoring, and baseline models.

---

## 2. Convolutional Neural Networks

### Mathematical model

For an image-like input (X), a convolutional layer computes:

[
Y_{i,j,k}=\phi\left(
b_k+
\sum_{u,v,c}
K_{u,v,c,k}X_{i+u,j+v,c}
\right)
]

where (K) is a learnable convolutional filter.

### Layer diagram

```text
Image / grid input
      ↓
Convolution filters
      ↓
Feature maps
      ↓
Activation
      ↓
Pooling / downsampling
      ↓
More convolution blocks
      ↓
Dense / classifier head
      ↓
Output
```

### Core idea

CNNs exploit **local spatial patterns** through small filters shared across the input. The same filter detects the same pattern in different positions.

### Strengths

They are excellent for spatial data because they use:

[
\text{local connectivity} + \text{parameter sharing} + \text{translation equivariance}
]

### Weaknesses

They are less naturally suited for long-range dependencies unless many layers or special mechanisms are added.

### Applications

Image classification, object detection, medical image analysis, segmentation, satellite imaging, visual inspection, and signal spectrogram analysis.

---

## 3. Recurrent Neural Networks

### Mathematical model

A basic recurrent neural network processes a sequence one step at a time:

[
h_t=\phi(W_xx_t+W_hh_{t-1}+b_h)
]

[
\hat{y}_t=g(W_yh_t+b_y)
]

where (h_t) is the hidden state at time (t).

For LSTM and GRU variants, gates are added to control memory and reduce vanishing-gradient problems.

### Layer diagram

```text
x1 → RNN cell → h1
x2 → RNN cell → h2
x3 → RNN cell → h3
...            ...
xT → RNN cell → hT
                 ↓
              Output
```

### Core idea

RNNs are designed for **ordered data**. The hidden state acts as a memory that summarizes previous inputs.

### Strengths

They naturally model temporal or sequential dependence.

### Weaknesses

They are harder to parallelize because each state depends on the previous state. Basic RNNs may suffer from vanishing or exploding gradients.

### Applications

Time-series forecasting, language modeling, speech processing, sequence classification, biomedical signals, control systems, and sensor data analysis.

---

## 4. Attention-Based Architectures / Transformers

### Mathematical model

Transformers use self-attention. Given an input matrix (X), they compute:

[
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V
]

[
\text{Attention}(Q,K,V)
=======================

\text{softmax}
\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
]

The attention matrix determines how much each token, patch, or element should attend to every other element.

### Layer diagram

```text
Input tokens / patches
      ↓
Embedding + positional encoding
      ↓
Multi-head self-attention
      ↓
Add & normalize
      ↓
Feed-forward network
      ↓
Add & normalize
      ↓
Output head
```

### Core idea

Transformers model **global relationships** directly. Every input element can interact with every other input element through attention.

### Strengths

They are highly parallelizable and very powerful for long-range dependencies.

### Weaknesses

Self-attention has high computational cost for long inputs:

[
O(n^2)
]

where (n) is the sequence length.

### Applications

Large language models, machine translation, text classification, image recognition with Vision Transformers, multimodal learning, protein modeling, code generation, and medical AI.

# Similarities

All four architectures:

1. Learn parameters using optimization, usually gradient descent or variants such as Adam.
2. Use nonlinear activation functions to approximate complex functions.
3. Can be stacked into deep models.
4. Can solve classification, regression, and representation-learning problems.
5. Require loss functions, backpropagation, and regularization to train effectively.

---

# Key Differences

The most important difference is the **assumption each architecture makes about the data**.

A dense network assumes the input is mostly a vector of features.

A CNN assumes nearby values are more related than distant values, which is ideal for images.

An RNN assumes the order of the data matters and that previous elements influence later ones.

A Transformer assumes that any element may be relevant to any other element and learns these relationships through attention.

# Final concise text for the infographic

**Dense networks** learn from flat feature vectors using fully connected layers. Their basic operation is (h=\phi(Wx+b)). They are simple and flexible, but they do not exploit spatial or temporal structure.

**Convolutional networks** learn local spatial patterns using shared filters. Their basic operation is convolution. They are ideal for images, object detection, and medical imaging because they exploit locality and translation equivariance.

**Recurrent networks** process ordered data step by step using a hidden state (h_t=\phi(W_xx_t+W_hh_{t-1}+b)). They are useful for time series, speech, and sequential signals, but they are harder to parallelize.

**Transformers** use self-attention,

[
\text{Attention}(Q,K,V)=\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V,
]

allowing every input element to interact with every other one. They are powerful for language, vision, and multimodal learning, but computationally expensive for long sequences.
