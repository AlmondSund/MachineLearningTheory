# Workshop 01: Regressors

Main notebook: `notebook.ipynb`

This workshop studies regression-based signal reconstruction under additive white Gaussian noise, including polynomial design matrices and multiple estimators such as OLS, Ridge, ML, and MAP.

## Topics

- Linear models, regularization, and estimator interpretation.
- Noisy data assumptions and model design.
- Estimator comparison and reconstruction quality.

This is a course workshop notebook, so assignment framing and exploratory cells
are kept in place.
