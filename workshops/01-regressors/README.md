# Workshop 01: Regressors

Main notebook: `notebook.ipynb`

This workshop studies regression-based signal reconstruction under additive white Gaussian noise, including polynomial design matrices and multiple estimators such as OLS, Ridge, ML, and MAP.

## Portfolio Evidence

- Foundation: linear models, regularization, and estimator interpretation.
- Demonstrates: translating noisy data assumptions into model design, comparing
  estimators, and reasoning about reconstruction quality.
- Status: course workshop artifact, preserved for evidence rather than polished
  as a standalone project.
