# Workshop 05: Time Series

Main notebook: [`notebook.ipynb`](notebook.ipynb)

This workshop builds synthetic time series from decomposition components and
uses autocorrelation to guide forecasting-window selection.

## Portfolio Evidence

- Foundation: experimental setup, time-series reasoning, and forecasting.
- Demonstrates: synthetic data construction, ACF-based window length selection,
  and next-step forecasting model comparison.
- Status: course workshop artifact, preserved for evidence rather than polished
  as a standalone project.
