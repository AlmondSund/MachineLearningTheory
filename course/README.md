# Course Context

This repository keeps materials from the Machine Learning Theory course at
Universidad Nacional de Colombia. The main folders follow the course activities:
workshops, midterms, and final project.

## How To Read The Repository

- Use [`../TOPIC_GUIDE.md`](../TOPIC_GUIDE.md) when you want to browse by
  subject instead of by assignment.
- Use [`../workshops/`](../workshops/) for guided practical notebooks.
- Use [`../midterms/`](../midterms/) for exam statements and solution material.
- Use [`../project/`](../project/) for the final project.

## Organization

| Folder | Contents |
| --- | --- |
| [`../workshops/`](../workshops/) | Practical notebooks and assignment-specific files. |
| [`../midterms/`](../midterms/) | Midterm PDFs, solution notebooks, challenge material, and presentation assets. |
| [`../project/`](../project/) | Voxter final project notebook, source modules, model files, and local run logs. |
| [`../data/`](../data/) | Local conventions for datasets and heavier generated artifacts. |

## Conventions

- Midterms use numeric folders such as `01` and `02`.
- Workshops use a numeric prefix plus a topic slug when available.
- Original statements and activity files stay near the corresponding notebooks.
- Course notebooks may contain derivations, exploratory cells, outputs, and
  assignment-specific assumptions in the same file.
